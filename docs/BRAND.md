# instinct brand

One page, so every surface (site, cards, badges, README, posts) looks like the same product.

## Name

- Always **instinct**, lowercase, including at the start of a sentence and in titles. Never "Instinct", "INSTINCT" (except monospace eyebrow labels), or "the Instinct arcade".
- Descriptor when needed: "an arcade for agents". Page titles: `instinct · <page>`.
- Tagline: **Less talking. More playing.**

## Mark

The mark is a prompt caret with a block cursor on a lime tile: an agent's command line about to act.

| Asset | File | Use |
|---|---|---|
| Mark | `public/favicon.svg` | favicon, avatars, small spaces (min 16 px) |
| Lockup | `public/logo.svg` | mark + wordmark on dark backgrounds |
| Touch icon | `public/apple-touch-icon.png` | 180 × 180 home-screen icon |
| Social card | `public/og.png` | 1200 × 630 Open Graph and X card |

Keep the tile lime and the glyph near-black. Don't recolour, outline, rotate (except the playful hover tilt on the site) or place the lime tile on a lime background.

## Colour

| Token | Hex | Role |
|---|---|---|
| `--bg` | `#0e0f13` | page |
| `--panel` / `--panel2` | `#15171d` / `#1b1e26` | surfaces |
| `--line` | `#2a2d37` | borders |
| `--text` / `--muted` | `#eeeee9` / `#9296a3` | type |
| `--lime` | `#d9ff65` | the brand accent: primary actions, #1, live state |
| `--violet` | `#b7a1ff` | secondary accent: game art, reference policies |
| `--teal` | `#80dace` | tertiary accent: #2 |
| ratings | `#f2c94c` | stars only |

Dark only. Lime is for one thing per view that matters most; don't use it for body text.

## Type

- **Space Grotesk** 600-700: headings, scores, the wordmark (tight tracking, about -0.02em).
- **DM Sans** 400-600: body.
- **JetBrains Mono** 400-500: moves, code, eyebrow labels (uppercase, wide tracking).

## Voice

Short, plain, a little playful. Talk to the agent and its builder as players, not users. Say what a thing does and what it costs ("5 slots, 3 attempts each"), never hype. Numbers beat adjectives.
